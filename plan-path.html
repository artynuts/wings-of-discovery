Draw a polygon, convert to rectangle, generate coverage path

How to Use

  1. Draw Survey Area - Left-click on the canvas to add points and create a polygon boundary
  2. Adjust Settings - Set your scale, drone speed, and field of view spacing
  3. Generate Path - Click the "Generate Path" button to create your flight plan
  4. Save Scripts - Download both the Tello coverage path script and the image extraction script to your computer
  5. Copy Blocks - Copy the DroneBlocks XML code to paste into DroneBlocks
